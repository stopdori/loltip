# 끊김 상호작용 참고표 (자동 생성)

> 이 문서는 `npm run gen:interrupt-ref`로 만들어지는 **보기용 파일**입니다. 직접 고치지 말고, 원본을 고친 뒤 다시 생성하세요.
> - 기본 규칙: `app/data/interactions/ccInteractions.ts`
> - 챔피언별 예외: `app/data/interactions/interruptOverrides.ts`
> - 스킬 태그: 각 챔피언 파일(`app/data/champs/*.ts`)의 gimmick 필드

## 1. 태그별 기본 규칙

| 분류 | 태그 | 기본적으로 끊는 CC |
|---|---|---|
| 이동기류 | 돌진 (`DASH`) | 체공, 경직, 에어본, 넉백, 그렙, 넉다운, 위치고정 |
| 이동기류 | 블링크 (`BLINK`) | 없음 |
| 이동기류 | 도약 (`LUNGE`) | 없음 |
| 이동기류 | 지형 통과 (`IGNORE_TERRAIN`) | 이동불가 전체, 변이 |
| 채널링류 | 채널링 (`SKILL_CHANNEL`) | 이동불가 전체(속박 제외), 침묵, 변이, 시전방해 |
| 채널링류 | 차징 (`SKILL_CHARGED`) | 이동불가 전체(속박 제외), 침묵, 변이, 시전방해 |
| 채널링류 | 이동채널 (`SKILL_CHANNEL_MOVEMENT`) | 이동불가 전체, 이동금지, 침묵, 변이, 시전방해 |

- 스킬에 저지불가(`UNSTOPPABLE`), CC면역(`CC_IMMUNE`), 시전강행(`CAST_COMMIT`) 중 하나가 같이 있으면 어떤 CC에도 끊기지 않음
- 이동불가 전체 = 에어본, 넉백, 그렙, 체공, 기절, 속박, 제압, 수면, 경직, 매혹, 도발, 공포, 광란
- 넉다운(`KNOCKDOWN`): 상태이상이 아니라 순간 효과로, **돌진만** 끊음 → 공포·매혹처럼 원래 돌진을 못 끊는 CC라도 넉다운이 붙어 있으면 돌진을 끊음
- 위치고정(`POSITION_LOCK`): 제압 등과 함께 걸려 대상 위치를 고정하며, **돌진을** 끊음 (예: 암베사 R, 크산테 R)
- 방해(`DISRUPT`): 상태이상이 아니라 순간 효과로, **채널링만** 끊음
- 계산 제외: 사일러스 R — 훔친 궁극기에 따라 판정이 달라서 계산에서 제외(모든 궁극기 판정을 정리한 뒤 마지막에 추가 예정)

## 2. 챔피언별 정리

챔피언 132명 / 끊길 수 있는 스킬 245개 / 추가로 끊는 효과 17개 (예외 등록 44건)

- **끊길 수 있는 스킬**: 이동기류·채널링류 태그가 붙은 스킬과, 그 스킬을 끊는 CC
  - "기본" = 1번 표의 규칙 그대로 / "추가"·"제외" = 예외 파일에 등록된 챔피언 고유 판정
- **기본 CC 이상으로 끊는 효과**: 넉다운·위치고정·방해가 붙은 스킬 (상대의 돌진·채널링을 추가로 끊음)
